# MATCHDAY ⚽

Plataforma web para crear, encontrar y registrar partidos de fútbol casual.

## Stack
- HTML5
- CSS3
- JavaScript Vanilla
- localStorage (sin backend por ahora)

## Funciones actuales
- Dashboard
- Registro de jugadores por posición
- Estadísticas específicas por posición
- Creación de partidos
- Solicitudes para unirse a partidos
- Notificaciones
- Estadísticas globales
- Torneos relámpago básicos
- Diseño responsive

## Ejecutar
Abrir index.html en el navegador. No requiere instalación ni servidor para esta versión.
