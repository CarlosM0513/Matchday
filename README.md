# MATCHDAY ⚽

Plataforma web para crear, encontrar y registrar partidos de fútbol casual.

## Stack
- HTML5
- CSS3
- JavaScript Vanilla
- localStorage para la versión sin backend
- GitHub Pages para publicación

## Funciones actuales
- Dashboard responsive
- Registro de jugadores por posición
- Estadísticas específicas por posición
- Perfiles de jugadores
- Creación de partidos
- Edición y eliminación de partidos creados por el usuario actual
- Solicitudes para unirse a partidos
- Protección local de acciones por propietario
- Prevención de solicitudes duplicadas
- Notificaciones locales
- Estadísticas globales
- Filtros y búsqueda de partidos
- Diseño responsive para móvil y escritorio

## Importante: almacenamiento actual
Esta versión funciona sin servidor y guarda los datos en localStorage. Por eso los datos de cada navegador son independientes. La propiedad y los permisos implementados actualmente son locales al navegador y **no sustituyen autenticación ni seguridad de servidor**.

## Próximas funciones que requieren backend
1. Cuentas y autenticación real
2. Datos compartidos entre usuarios y dispositivos
3. Permisos de servidor / RLS
4. Actualizaciones en tiempo real
5. Equipos y plantillas compartidas
6. Eventos y estadísticas de partidos sincronizadas
7. Alineaciones y torneos compartidos
8. Matchmaking compartido
9. Canchas y disponibilidad compartidas

## Ejecutar
Abrir index.html en el navegador o usar GitHub Pages. No requiere instalación para esta versión.
